# 🚨 SafeSignal

SafeSignal is a real-time emergency alert system designed to improve personal safety by sending instant location-based alerts to trusted contacts.

---

## 🔥 Features
- One-tap emergency SOS alert
- Real-time Firestore database updates
- User authentication utilities
- Notification system (ready for SMS/push integration)
- Modular backend architecture

---

## 🛠️ Tech Stack
- Node.js
- Firebase Firestore
- Express.js (if used)
- JavaScript

---

## 📁 Project Structure
- firebase/ → Firebase configuration
- utils/ → Helper functions (auth, DB, notifications)
- services/ → Core business logic (alerts system)
- index.js → Entry point
